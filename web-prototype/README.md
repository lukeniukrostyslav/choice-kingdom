# Choice Kingdom — Visual Prototype

This is the first interactive visual validation surface for the premium UI direction.

## Scope

- Event / decision screen
- Realistic Choice Kingdom visual language
- Choice idle / pressed / resolving / resolved behavior
- Realm summary
- History surface
- People surface
- Responsive portrait layout
- Large-text-friendly structure
- Reduced-motion support

## Important boundary

This prototype is **visual validation only**. Its sample interaction state does not replace `runtime.GameSession` and does not claim production gameplay integration. The production UI must later consume the presentation-neutral `GameSession` contract.

## Vercel

The repository can be deployed with the Vercel project root configured to the repository root. `vercel.json` routes the root page to this prototype.
