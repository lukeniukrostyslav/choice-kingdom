# Choice Kingdom

Original premium decision-and-consequence mobile game.

## Product direction

Choice Kingdom takes inspiration from the **high-level structure** of decision-driven games such as Reigns: short situations, two meaningful choices, persistent consequences, characters, resources, event chains, and multiple endings.

This project is **not a clone**. All worldbuilding, characters, writing, events, artwork, mechanics, UI, and code must be original.

## Target product

- Android-first premium game
- Offline-first; no mandatory online service
- No advertising
- No subscriptions
- No required backend for the core game
- Target price: approximately €2.99–€4.99
- Short, replayable sessions
- Decisions should create delayed and non-obvious consequences
- Multiple endings and replay paths

## Core loop

1. Present a situation.
2. Offer two meaningful opposing choices.
3. Apply immediate state changes.
4. Record the decision history.
5. Allow delayed consequences to surface later.
6. Introduce new events based on state, history, characters, and conditions.
7. Continue until an ending condition is reached.
8. Allow replay with a different path.

## Initial game concept

Working theme: **ruling a kingdom**.

Possible state dimensions:

- Gold / economy
- Public trust
- Security / military strength
- Political power
- Reputation

The final names, values, balancing, world, characters, and story are intentionally not locked yet.

## Long-term strategy

The project should be designed around a reusable decision-game engine. Once the engine is proven, the same technology can support future original premium games with different themes, such as space command, detective investigation, corporate management, survival, piracy, or AI management.

## Development rule

No fake gameplay, placeholder business logic presented as finished, or premature production-readiness claims. The project must progress from specification → architecture → playable vertical slice → automated verification → content expansion → Android QA → release preparation.

`rulebreak8` is a separate project and must not be modified as part of this repository.
