## Verified recurring People

The authoritative narrative source and authored source patch explicitly use these six recurring character names:

- Mara
- Rowan
- Seris

- Toma

They are the only six names promoted by this freeze.

## What is NOT canonized

Artwork alone must not establish:
- exact age;
- exact facial features;
- personality adjectives;
- motives;
- invented quotations;
- exact clothing;
- exact faction membership;
- relationship state;
- availability/unlock state;
- invented titles or ranks;
- portrait provenance.

The existing visual roster study is explicitly study-only and noncanonical.

## Production art rule

Character artwork must bind to one verified People name, preserve a stable visual identity anchor, respect the world/material grammar, remain readable at compact mobile portrait size, keep the face/identity dominant, never imply runtime relationship/faction state, and record production-art provenance/licensing before final production approval.

## P25 visual target

Use the approved Choice Kingdom premium language: cinematic medieval fantasy; deep blue-black / charcoal foundation; restrained warm-gold accents; elegant serif hierarchy; layered refined panels; generous spacing; consequential narrative presentation; responsive reflow; RTL; large text and long strings; safe areas; reduced motion.

This freeze is a canonical boundary and visual QA aid. It does not by itself close P2/P3 or P25.
