# Choice Kingdom — P17 Replay / New-Reign Design Contract

## Premium intent
Replay is framed as discovery: a new reign starts with a clean decision state, while the previous chronicle remains a readable record. The interface must clearly distinguish history from gameplay state and must not imply hidden mechanical advantage.

## Surface contract
- New Reign is the primary action.
- Previous Chronicle remains accessible.
- Carry-forward memory is explicit and narrative, not an unexplained gameplay bonus.
- Divergence is communicated as authored possibility rather than a generic reset.
- Responsive mobile-first layout with safe-area compatibility.
- RTL, large text, keyboard/focus and reduced-motion behavior remain supported.

## Evidence
Representative surface: `web-preview/design-replay-p17-premium.html`.

P17 is not closed at 100% by this contract alone; Android binding, complete interaction proof and regression evidence remain required.
