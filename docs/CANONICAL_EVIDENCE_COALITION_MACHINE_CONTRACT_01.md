# Choice Kingdom — Evidence & Coalition Machine Contract 01

Date: 2026-09-15
Status: SOURCE-LEVEL QA CONTRACT — NOT RUNTIME
Scope: E01–E277

## 1. Systemic explanation

`pred.systemic_explanation_verified` may be true only when the run contains all four explicit components:

1. warehouse/financial evidence identity;
2. document/language evidence identity;
3. witness/organizational evidence identity;
4. an explicit convergence marker linking the three classes into one explanation.

Repeated evidence from the same class does not satisfy an independent class. A consumer event cannot manufacture a missing evidence class. Evidence must be retained in save/load and replay state without cross-run leakage.

## 2. Coalition cooperation

`pred.coalition_cooperation` requires an explicit cooperation package, not merely multiple active character routes. The package must record:

- explicit cooperation declaration;
- participant identities;
- positive cooperation outcome;
- no unresolved exclusive/broken/collapse blocker.

E148-A is the early authored cooperation-package candidate. E261-A is a later explicit four-way cooperation package candidate. E264 break/collapse semantics must invalidate active cooperation while preserving historical evidence. A selective or exclusive package cannot qualify as the full cooperation predicate unless the canonical contract explicitly says so.

## 3. Ordering

A producer must become valid before any consumer that depends on it. Later convergence events cannot retroactively satisfy an earlier eligibility check. Negative branches must be represented explicitly and must prevent accidental qualification.

## 4. Gate

This contract remains PARTIAL until exact event-choice identifiers are reconciled against the authoritative catalog, all producers/consumers are ordered, contradiction/cycle/reachability checks pass, and save/load/replay semantics are represented. It is not an engine schema.
