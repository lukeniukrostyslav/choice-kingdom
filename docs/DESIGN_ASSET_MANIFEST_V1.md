# Choice Kingdom — Design Asset Manifest v1

| Family | Purpose | Final asset requirements |
|---|---|---|
| Event illustrations | Establish scene/stakes | stable ID, portrait focal point, crop-safe region, provenance |
| Character portraits | Humanize relationships | consistent framing, identity-safe provenance |
| Faction marks | Distinguish constituencies | neutral symbolism, provenance |
| Ending illustrations | Close chronicle | ending-specific composition, provenance |
| UI icons | State/navigation | semantic meaning, accessible label |

An asset is final only when its ID, usage, crop behavior, source/license provenance and QA checkpoint are recorded.

Prohibited as final identity: generic stock/game UI packs, placeholder icons, art that hides decisions, or faction imagery that encodes good/evil by default.
