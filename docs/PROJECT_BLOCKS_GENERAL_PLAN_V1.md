## Non-negotiable execution rule

The active block is Block 1. Do not advance the project plan merely because a later layer can be worked on. Later work may only be used when it is required to close the active block or preserve existing contracts.

## Design rule

Premium Design P1–P25 is preserved, not abandoned. It is intentionally scheduled after the real gameplay/runtime layers exist so final design can be validated against real states. When Block 13 becomes active, every P1–P25 block must reach real 100% using implementation, responsive/accessibility/RTL evidence and regression proof applicable to that block.

## Completion rule

A block is 100% only when its required implementation, integration, verification, regression evidence and production constraints are satisfied. Source-level or documentation-only completion must be labeled as such and must not be presented as runtime completion.
