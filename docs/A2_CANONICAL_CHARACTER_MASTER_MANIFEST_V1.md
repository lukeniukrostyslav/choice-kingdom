## Canonical boundaries

The repository explicitly does NOT canonize exact age, exact facial features, exact clothing, invented quotes, exact faction membership, relationship state, availability/unlock state or portrait provenance from artwork alone.

Therefore the production master may not silently invent these fields.

## Production master-sheet contract

Each of the six characters must eventually receive:
1. front neutral;
2. three-quarter neutral;
3. side/profile;
4. full-body proportion reference;
5. close face crop;
6. minimum six controlled expressions;
7. default costume-layer reference;
8. signature-material/accessory callouts only where canonically supported;
9. portrait crop-safe framing;
10. prohibited-drift examples.

The master sheet is the source for later portraits, expressions and scenes.

## Cross-character consistency gate

Compare all six together for:
- same Avelune world/material grammar;
- same illustration/rendering family;
- compatible lighting direction;
- compatible portrait framing;
- distinct silhouettes;
- no accidental faction moral coding;
- no invented lore;
- mobile thumbnail readability.

## Event-context binding

Art must be linked to repository-backed narrative use, not merely a character name.

Known narrative routes:
- Mara: accounting / institutional investigation.
- Rowan: guard / security / border pressure.
- Seris: noble houses / elite participation.
- Ivo: merchants / river trade / market pressure.
- Amara: House of Lanterns / medicine / civic relief.
- Toma: docks / information / physical evidence.

The Event Graph contains many authored nodes, but graph presence alone does not prove runtime execution. An image must therefore not be labeled as a runtime event asset until the corresponding production/runtime binding is verified.
