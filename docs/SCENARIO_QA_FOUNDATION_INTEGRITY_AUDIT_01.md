**Scope:** E01–E272 production semantics; E273–E277 excluded  
**Purpose:** strengthen the canonical foundation before unresolved E33/E34 recovery and before production schema / Decision Engine work.

## 1. Frozen scope

- Production event scope is E01–E272.
- E273–E277 remain expansion-only and cannot satisfy production predicates, producers, consumers, or reachability.
- E33/E34 remain quarantined because their authoritative authored headings/effects have not been recovered.
- No replacement semantics are authored by this audit.

## 2. Canonical source boundary

The machine canonical graph identifies the authoritative event catalogs, design graph, producer inventory, producer/consumer registry, delay contract, and derived-predicate contract as source inputs.

This audit treats those documents as evidence sources, not as proof of executable gameplay semantics. A machine contract may declare a boundary while producer identity, lifecycle, reachability, and runtime behavior remain unresolved.

## 3. Foundation invariants

### Event identity

- Every production event ID must remain within E01–E272.
- Duplicate event IDs are prohibited except for the explicitly allowed E271 catalog duplication.
- E33/E34 references may remain visible in recovery inventories but must not be promoted to canonical event semantics without authoritative source evidence.

### Producer/consumer separation

- A consumer cannot manufacture the prerequisite it consumes.
- A prose reference is not automatically an executable producer.
- Relationship values cannot substitute for institutional evidence domains.
- Ordinary history/flags do not become replay `meta.*` state without an explicit authored promotion contract.

### Predicate separation

- `pred.food_stable` is not interchangeable with `food_logistics_stabilized`.
- `pred.market_pressure` and `pred.winter_severe` are authored cycle-scoped predicates and must not be inferred merely from downstream references.
- `pred.budget_reform` requires the three source-closed components: auditor independence, crown audit, and legislative budget lock.
- Composite predicates remain bounded by their explicit domain/convergence requirements.

### Delayed consequences

Source identity and runtime lifecycle are separate gates. A source-identified producer does not by itself prove scheduler anchoring, cancellation, supersession, exactly-once behavior, persistence, or replay isolation.

### Reachability

Structural graph reachability is not gameplay reachability. No connected graph, path candidate, or trigger reference is promoted to a playable route until stateful conditions and contradictions are checked.
