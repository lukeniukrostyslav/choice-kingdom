## Non-negotiable production rule
External research may inform production methodology and technical constraints. It must never invent Choice Kingdom lore.

No asset may silently invent:
- character identity or biography;
- exact age/facial features/clothing;
- relationship state;
- faction membership;
- titles/ranks;
- quotes;
- locations;
- symbols/crests;
- event meaning;
- gameplay consequences.

If a detail is not canonical, leave it unresolved or use the smallest neutral treatment.

## A2 acceptance
A2 reaches 100% only when all six production masters:
- are bound to the six verified names;
- preserve stable identity anchors;
- use the same Avelune visual/rendering family;
- have production provenance/licensing recorded;
- pass 360dp and 412dp mobile readability;
- survive large text, RTL and safe-area layouts;
- are integrated and backed by visual QA evidence.
