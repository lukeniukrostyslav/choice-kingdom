# Choice Kingdom — Reachability Pre-Audit 03

Date: 2026-09-15
Status: STATIC PRE-AUDIT / NOT RUNTIME VALIDATION

## Purpose

Establish the next reachability gate from the unified producer/consumer registry before a machine-readable catalog is frozen.

## Entry principle

Reachability must be evaluated from real campaign entry conditions through authored choice consequences, durable state, thread activation, delayed consequences and event prerequisites. A graph edge alone is insufficient.

## Terminal targets

The seven ending families are qualified through E265–E270. The pre-audit therefore tracks reachability into the qualification layer rather than treating a last event as an ending resolver.

## Cycle-risk checks

- Final qualification cannot produce its own prerequisites.
- E210 is a convergence node only.
- Coalition qualification must not be circular with faction-route count.
- Systemic truth must depend on independent evidence markers.
- Border crisis must remain independent of security resource.
- Food stability must remain independent of a sixth resource.

## Reachability test cases to author after closure

At minimum, deterministic scenarios must cover:

- institutional positive route → Steward;
- concentrated military route → Iron Crown;
- commercial route → Golden Compact;
- civic route → People's Charter;
- unresolved compound crisis → Broken Diadem;
- explicit withdrawal route → Quiet Throne;
- investigation + systemic proof + coalition + constitutional redesign → Second Founder.

Each scenario must record event sequence, choices, state deltas, delayed effects, terminal predicates and ending result.
