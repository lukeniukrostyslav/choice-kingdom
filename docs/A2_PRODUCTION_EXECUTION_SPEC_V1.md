## Master-sheet requirements

Each character master must contain:
1. front neutral;
2. three-quarter neutral;
3. side/profile;
4. full-body proportion reference;
5. close face crop;
6. at least six controlled expressions;
7. default costume-layer reference;
8. only canonically supported material/accessory callouts;
9. crop-safe portrait framing;
10. prohibited-drift examples.

The master sheet is a source asset for later portraits and scenes, not automatically the final in-game image.

## No-invention boundary

If the repository does not specify an exact age, facial feature, garment, accessory, faction membership, color identity, quotation, relationship state, or other character fact, production art must use a neutral treatment rather than silently declaring a new canon fact.

## Visual family lock

All six characters must share:
- the same editorial/painterly/historical-fantasy rendering family;
- the same Avelune material grammar;
- one coherent lighting grammar;
- compatible portrait framing;
- restrained warm-gold treatment;
- quiet backgrounds behind faces;
- mobile-readable silhouettes.

The six characters must be visibly distinct without using faction color as a good/evil signal.

## Iteration rule

Do not create hundreds of unrelated images first. Lock identity masters first, then derive portraits, expressions, event scenes, environments, props and institutional assets from those approved masters.

## QA rule

A character cannot be marked production-ready from documentation alone.

Every production master must eventually have evidence for:
- identity consistency;
- thumbnail readability;
- 360dp;
- 412dp;
- large text;
- RTL;
- safe-area composition;
- runtime integration;
- provenance/licensing.
