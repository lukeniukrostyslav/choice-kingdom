# Choice Kingdom — Final Design Vision V1

Status: **CANONICAL VISUAL REFERENCE — ACTIVE**

This document records the approved visual direction represented by the generated final-design concept image shown in the project conversation on 2026-09-17. The image is the visual north-star reference; implementation should converge toward this direction without copying proprietary artwork, branding, or UI from other games.

## Visual north star

- Premium cinematic medieval-fantasy presentation.
- Avelune is the visual world: monumental castle/city, mountains, water, forests, roads and regional map detail.
- Deep blue-black / charcoal surfaces with restrained warm gold metal accents.
- Elegant high-contrast serif display typography for titles, paired with highly readable supporting text.
- Atmospheric authored artwork is prominent but never allowed to compromise readability.
- Panels are refined, layered and slightly translucent/opaque enough to preserve text contrast.
- Choices feel consequential: clear hierarchy, meaningful labels, visible state feedback and restrained semantic color.
- Consequence screens communicate immediate and delayed effects without clutter.
- Realm, People, Investigation and History screens use information-dense layouts while preserving generous spacing and visual hierarchy.
- Endings provide a cinematic emotional landing rather than a utilitarian result screen.
- Settings remain premium and calm, with accessibility controls treated as first-class product features.
- Compact phone, medium tablet/foldable and expanded layouts preserve the same identity while reflowing navigation and content.
- LTR, RTL, long strings and large text must preserve hierarchy and touch ergonomics.
- Motion is subtle and semantic; reduced-motion removes decorative movement without removing state feedback.

## Implementation rule

This reference is a **directional visual contract**, not permission to invent gameplay. Gameplay state remains owned by the canonical runtime/session layer. UI presents state; it does not calculate outcomes.

## Acceptance target

Future visual work should be evaluated against this reference for:
- visual hierarchy
- premium material language
- typography
- spacing
- choice readability
- state feedback
- cinematic atmosphere
- responsive composition
- accessibility
- cross-screen consistency

Do not mark a P1–P25 block 100% merely because it visually resembles this reference. The canonical exit gates still require implementation, responsive behavior, accessibility evidence and regression proof.
