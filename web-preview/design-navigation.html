A visual contract for moving between the eight production screens. Navigation communicates location and preserves decision authority: presentation changes screen state, while gameplay remains owned by the runtime.

Transition states
Idle

Navigation is available and current location is exposed.

Resolving

Decision controls are locked; no duplicate submission.

Disabled

Unavailable destination remains understandable by text/semantics.

Resolved

Outcome is visible before optional exploration.

Deep link / restore

Screen can restore presentation from canonical runtime state.

Reduced motion

No required information depends on animation.

Cross-screen invariants
  • Internal event IDs are never presented as player-facing navigation labels.
  • Current location is semantic and remains clear without color.
  • RTL mirrors layout without changing meaning or choice order semantics.
  • Large text may reflow; decision controls must not clip or disappear.
  • Safe-area and gesture insets are respected on every destination.
  • Navigation never exposes future consequences as present facts.
