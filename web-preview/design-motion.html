Choice Kingdom · interaction motion

Motion & Micro-interaction Lab

Motion communicates state change and hierarchy. It never carries information that disappears when animation is disabled, and it never grants gameplay authority.

Timing

Default transition: 180ms

Intent: short, calm, state-oriented.

Reduced motion: animation and transition are removed without semantic loss.

Choice lifecycle
Idle · available
Focused · visible focus
Pressed · immediate acknowledgement
Resolving · locked against duplicate submission
Resolved · consequence state exposed
Interactive demo

The resolving state is understandable even with motion disabled.

Rules

Do not animate future consequences into the present.

Do not use motion as the only state signal.

Do not delay a decision acknowledgement for decorative animation.

Do not reorder semantic content through animation.

Screen transitions

Event → result: outcome is perceptually anchored to the submitted decision.

Result → Realm/History: destination appears after runtime resolution.

Deep links/restoration: state is restored without requiring a transition to convey meaning.

Acceptance

✓ 180ms default intent

✓ Reduced-motion safe

✓ No semantic dependence on animation

✓ No double submission

✓ Focus remains visible
